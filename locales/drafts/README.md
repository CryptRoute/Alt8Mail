# Machine-translation drafts

These catalogs are proposals, not runtime locales. They are generated by
`scripts/i18n-draft.mjs` and never loaded by the webmail or listed in the
language selector.

- `<catalog>.json` — reviewed live values plus machine-translated missing keys.
- `<catalog>.meta.json` — model, source hash, counts and failed keys.

Review with `npm run i18n:review -- --locale <code>` and promote only after a
native review with `scripts/i18n-promote.mjs --locale <code> --reviewed-by
"Name" [--enable]`. See [docs/TRANSLATION_WORKFLOW.md](../../docs/TRANSLATION_WORKFLOW.md).

Do not edit these files to change the source wording; edit `locales/en.json`
and regenerate the draft.
